## 🚀 PASOS PARA SUBIR A GITHUB PAGES

1. Crea un repositorio público en GitHub llamado `lapbook-cultura-digital`.
2. Sube todos los archivos manteniéndolos en la raíz del repositorio (`index.html`, `style.css`, `script.js`, `contenido.js` y la carpeta `images/`).
3. En GitHub, ve a **Settings** (Configuración) > **Pages**.
4. En **Source** / **Branch**, selecciona `main` o `master` y guarda.
5. En unos momentos obtendrás tu enlace público listo para entregar:
   `https://tu-usuario.github.io/lapbook-cultura-digital/`
